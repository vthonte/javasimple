1 Code Lab 1: Grouping Orders by Customer and Calculating Total Spend

Given a list of Order objects with customerId and amount, produce a summary map: { customerId -> totalSpent }.

Node.js (Array.prototype.reduce) JavaScript Standard 
// Node.js: reduce into an accumulator object
function calculateCustomerTotals(orders) {
  return orders.reduce((acc, order) => {
    const { customerId, amount } = order;
    acc[customerId] = (acc[customerId] || 0) + amount;
    return acc;
  }, {});
}

// Result: { "cust_101": 250.50, "cust_102": 89.00 }
Java 8 (Streams & Collectors.groupingBy) Java 8 Functional Pipeline 
// Java 8: Streams API with Collector composition
public Map<String, Double> calculateCustomerTotals(List<Order> orders) {
    return orders.stream()
        .collect(Collectors.groupingBy(
            Order::getCustomerId,                        // Classifier (Key)
            Collectors.summingDouble(Order::getAmount)   // Downstream reduction (Value)
        ));
}
// Type-safe, compiled at build time, zero raw string type casting!
Modern Java 21 (Records + Pattern Matching + Parallel Stream) Modern Java Clean Architecture 
// 1. In Java 16+, 'record' replaces boilerplate POJO DTOs with auto-generated getters, equals, hashCode:
public record Order(String customerId, double amount, String status) {}

// 2. High-throughput calculation across millions of records using multi-core parallelStream:
public Map<String, Double> calculateHighVolumeTotals(List<Order> orders) {
    return orders.parallelStream() // Automatically utilizes all 16 CPU cores!
        .filter(order -> "COMPLETED".equalsIgnoreCase(order.status()))
        .collect(Collectors.groupingByConcurrent(
            Order::customerId,
            Collectors.summingDouble(Order::amount)
        ));
}

@Service
public class TokenCacheService {
    // DISASTER: Multiple threads calling put/get simultaneously!
    private Map<String, UserToken> cache = new HashMap<>();

    public UserToken getToken(String userId) {
        if (!cache.containsKey(userId)) {
            // Check-then-act race condition!
            cache.put(userId, fetchFromDB(userId));
        }
        return cache.get(userId);
    }
}
// Consequence: Thread 1 & 2 resize the map at the same time.
// Result: Infinite loop, corrupted internal bucket pointers, 100% CPU lock!
âœ… Senior Code: Atomic computeIfAbsent in ConcurrentHashMap
@Service
public class TokenCacheService {
    // Thread-safe with segment-level lock striping
    private final ConcurrentMap<String, UserToken> cache = 
        new ConcurrentHashMap<>();

    public UserToken getToken(String userId) {
        // ATOMIC: If absent, executes loader function once.
        // Other threads wait for value without blocking entire map!
        return cache.computeIfAbsent(userId, this::fetchFromDB);
    }
}
// Result: 100% thread-safe, lock-free reads, non-blocking writes!
