Java Loops, Conditionals & Modern Pattern Matching Switch

Everything you need to know about looping and branching in Java: for-loops, while/do-while, enhanced for-each, labeled break/continue, and the modern Java 21 Switch Expressions with pattern matching.

💡

ELI5: Loops in JS vs Java (Surprise: They're 95% Identical!)

If you know for (let i = 0; i < n; i++), you already know Java! In Java, you simply write for (int i = 0; i < n; i++).

The only major difference is JavaScript's for (const item of list) becomes Java's enhanced for-each loop: for (String item : list) using a colon (:) instead of the word of!

The 4 Types of Loops (JavaScript vs Java)

1. Standard Indexed For-Loop

JavaScript 
for (let i = 0; i < 5; i++) {
  console.log(`Index: ${i}`);
}
Java 
for (int i = 0; i < 5; i++) {
  System.out.println("Index: " + i);
}

2. Enhanced For-Each Loop (Iterating Lists & Arrays)

Notice the syntax: for (Type variable : collection)

JavaScript (for...of) 
const fruits = ["Apple", "Banana", "Orange"];
for (const fruit of fruits) {
  console.log(fruit);
}
Java (for : ) 
List<String> fruits = List.of("Apple", "Banana", "Orange");
for (String fruit : fruits) {
  System.out.println(fruit);
}

3. While & Do-While Loops

int count = 0;
// while: Checks condition BEFORE running
while (count < 3) {
    System.out.println("Count is: " + count);
    count++;
}

// do-while: Always runs AT LEAST ONCE before checking condition
int attempts = 0;
do {
    System.out.println("Attempting connection...");
    attempts++;
} while (attempts < 1);

4. Loop Control: Break, Continue & Labeled Breaks

Break exits immediately; Continue skips to next iteration. Java also supports Labels to break out of nested outer loops directly:

outerLoop: 
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) {
            // Breaks BOTH inner and outer loops in 1 step!
            break outerLoop;
        }
        System.out.println("i=" + i + ", j=" + j);
    }
}
Modern Java 21 Feature No break statements needed!

Modern Switch Expressions & Pattern Matching

Forget old C-style switch with ugly break; statements that fall through if forgotten! Modern Java uses arrow syntax (->) and returns values directly: 

// Switch returns a value directly into a variable!
int statusCode = 404;

String message = switch (statusCode) {
    case 200 -> "OK: Success";
    case 400, 404 -> "Client Error: Resource Missing";
    case 500 -> "Server Error";
    default -> "Unknown Code";
};

// Java 21 Pattern Matching on Objects:
Object obj = "Hello";
String result = switch (obj) {
    case Integer i -> "Integer of value: " + i;
    case String s  -> "String of length: " + s.length();
    default        -> "Something else";
};
