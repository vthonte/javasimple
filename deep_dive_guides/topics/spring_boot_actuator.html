Spring Boot Actuator: Health Checks, Metrics & Kubernetes Probes

Production-ready features out of the box: Liveness and Readiness probes for Kubernetes, exposing Prometheus metrics, inspecting thread dumps, and securing sensitive actuator endpoints.

💡

ELI5: The Hospital Heart Monitor & Vitals Dashboard

In Node, developers manually code custom app.get('/health', ...) routes and install prom-client to measure traffic and memory.

Spring Boot Actuator adds a full telemetry dashboard with zero custom code. Adding spring-boot-starter-actuator instantly wires health checks for your database, Redis cache, and disk space, plus tracks JVM memory and HTTP request percentiles.

☸️ Kubernetes Liveness vs. Readiness Probes

/actuator/health/liveness

Question: "Is the JVM running and not deadlocked?"
Action if FAIL: Kubernetes kills the container and restarts the pod!

/actuator/health/readiness

Question: "Is the database reachable and cache warm?"
Action if FAIL: Kubernetes stops sending user traffic, but does NOT restart the pod.

Configuring & Securing Actuator Endpoints

By default, only /health is exposed over HTTP for security. Expose metrics and prometheus in application.yml:

management:
  endpoints:
    web:
      exposure:
        include: "health,info,metrics,prometheus" # NEVER expose 'env' or 'shutdown' publicly!
  endpoint:
    health:
      show-details: when-authorized
      probes:
        enabled: true # Enables K8s liveness & readiness groups
  metrics:
    export:
      prometheus:
        enabled: true # Scraped by Prometheus / Grafana at /actuator/prometheus
