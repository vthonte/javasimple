Resilience & Fault Tolerance: Resilience4j Circuit Breakers, Retries & Bulkheads

Preventing cascading failures in distributed microservices: the 3 states of a Circuit Breaker (CLOSED, OPEN, HALF_OPEN), exponential backoff with jitter, Rate Limiters vs Bulkheads, and fallback mechanisms.

💡

ELI5: The Electrical Fuse in Your House

If a lightning strike causes an electrical power surge in your home, the fuse trips (opens the circuit) instantly to cut off power, preventing all appliances in your house from catching fire.

In microservices, if Payment Gateway B is down and taking 30 seconds to timeout, your threads pile up waiting. Without a Circuit Breaker, your entire service runs out of threads and crashes (cascading failure). With Resilience4j, after 5 failures the circuit OPENS: calls fail fast immediately (0ms) and return a fallback response, saving your servers!

📊 Circuit Breaker States Visualized

1. CLOSED (Normal)

All requests pass through to the downstream service. Failure rate is tracked in a sliding window.

2. OPEN (Tripped)

Threshold exceeded (>50% errors). Requests are short-circuited immediately with fallback response!

3. HALF_OPEN (Testing)

Wait duration elapsed. Lets 10 trial requests through. If successful -> CLOSED; if failed -> OPEN.

Implementing Resilience4j with Fallback

@Service
public class PaymentGatewayService {

    // Circuit Breaker + Retry + Fallback method!
    @CircuitBreaker(name = "paymentService", fallbackMethod = "paymentFallback")
    @Retry(name = "paymentService")
    public PaymentResponse chargeCard(PaymentRequest req) {
        // Calls external Stripe / PayPal API
        return restTemplate.postForObject("https://api.stripe.com/charge", req, PaymentResponse.class);
    }

    // Fallback executes when downstream service fails or circuit is OPEN!
    public PaymentResponse paymentFallback(PaymentRequest req, Throwable t) {
        logger.warn("Payment service unavailable, queuing payment offline", t);
        return new PaymentResponse("QUEUED_OFFLINE", "Payment accepted and will process shortly");
    }
}
